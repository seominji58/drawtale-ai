# 모델 학습 및 성능 테스트 결과

## 1. 모델별 학습 결과

### 모델 1 — 초기 모델

- 학습 조건: 30 Epoch, Batch Size 256
- 데이터 분할 비율: 90:5:5 (훈련:검증:테스트)
- 설정 목적: 이미지 모델의 학습 데이터 비중을 높여 검출 성능을 향상시키고자 함.
- 정확도: 94.3%

### 모델 2 — 추가 학습 모델

- 학습 조건: 모델 1에서 12 Epoch 추가 학습
- 정확도: 95.9%
- 특이사항: 모델 1보다 정확도가 향상되었으나, 추가 학습으로 인한 과적합 가능성이 있어 별도의 검증이 필요함.

### 모델 3 — 하이퍼파라미터 재조정 모델

- 학습 조건: 하이퍼파라미터 재설정 후 처음부터 학습
- 학습 설정: 30 Epoch, Batch Size 256
- 데이터 분할 비율: 7:1:2 (훈련:검증:테스트, 교수님 추천 비율)
- 정확도: 90.9%
- 성능 저하 원인 추정: 모델 1·2보다 훈련 데이터 비중이 감소하면서 학습에 활용되는 이미지 수가 줄어들어 검출 성능이 낮아졌을 가능성이 있음. 다만, 데이터 분할 비율 외의 설정도 변경되었으므로 추가적인 비교 검증이 필요함.

## 2. 모델별 성능 비교

| 구분   | 학습 방식                 | 데이터 분할 비율 | 정확도   |
| ---- | --------------------- | --------- | ----- |
| 모델 1 | 최초 학습 30 Epoch        | 90:5:5    | 94.3% |
| 모델 2 | 모델 1에서 12 Epoch 추가 학습 | 90:5:5    | 95.9% |
| 모델 3 | 설정 변경 후 처음부터 학습       | 7:1:2     | 90.9% |

현재까지는 모델 2의 정확도가 가장 높았으며, 이를 기준으로 실제 춤 영상에 대한 간단한 성능 테스트를 진행함.

## 3. 실제 춤 영상 테스트

테스트 목적

관절 정보가 사전에 지정되지 않은 무작위 춤 영상에서도 관절을 추출하고, 추출한 관절을 활용해 캐릭터가 춤 동작을 따라 할 수 있는지 확인함.

테스트 결과

- 모델 2를 활용해 춤 영상에서 관절을 추출하고, 해당 관절 정보를 바탕으로 춤 동작을 재현함.
- 테스트 결과에서 가장 높은 검출률은 \*\*65%\*\*로 확인됨.
- 관절별 검출률은 별도로 측정하지 않음. 테스트 영상의 관절 정보를 사전에 추출·정제하지 않은 상태로 사용했기 때문에, 기존 평가와 동일한 기준으로 비교하기 어려웠음.

## 4. 향후 개선 방향

실제 영상에서의 검출 성능을 높이기 위해서는 다양한 춤 영상에서 관절 데이터를 추출하고 정제한 뒤, 이를 학습 데이터에 추가하여 모델을 개선할 필요가 있음.

향후에는 관절 데이터의 품질을 확보하고, 동일한 평가 기준으로 모델별 성능을 비교하여 실제 영상에서의 관절 검출 성능을 향상시키는 것을 목표로 함.
