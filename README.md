##작업 요약
-첫번째 모델: 30epoch 256 batch 분할 비율 90:5:5(이미지 모델이니 만큼 이미지 학습에 많은 데이터를 넣어서 성능을 강화하는게 목적) | accuracy = 0.943
-두번째 모델: 첫번째 모델에 12epoch 추가로 학습시킴 | accuracy 0.959 (단 과적합 됐을 가능성 있음)
-세번째 모델: 하이퍼파라미터 재조정해서 처음부터 싹다 새로 학습시킴 30epoch batch 256 분할 비율: 7.1.2(교수님 추천 비율) | accuracy 0.909 | 이미지 학습 모델에서 훈련에 쓰이는 이미지가 감소하여 검출률이 낮아졌다 추측

-간단 성능 테스트
가장 검출률이 좋았던 두번째 모델로 관절 지정안한 무작위 춤 영상의 관절을 적출하여 춤 동작 따라하게 만듦. 관절별로 검출률 측정 안한 이유는 테스트 때 사용한 동영상의 관절을 적출안한 채 사용하였기에 똑같은 평가기준으로 측정할 수 없었다. 결과는 가장 높은것이 0.65로 이후 학습에서는 동영상에서 관절을 적출하고 정제하여 모델에 추가로 학습시킬 필요가 있음. 향후 작업 목표 또한 같음을 시사함
