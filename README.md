# 모델 학습 및 성능 테스트 결과

## 1. 모델별 학습 결과

### 모델 1 — 초기 모델

- 학습 조건: 30 Epoch, Batch Size 256
- 데이터 분할 비율: 90:5:5 (훈련:검증:테스트)
- 설정 목적: 이미지 모델의 학습 데이터 비중을 높여 검출 성능을 향상시키고자 함.
- 정확도: 94.3%

### 모델 2 — 추가 학습 모델

- 학습 조건: 모델 1에서 12 Epoch 추가 학습
- 정확도: 95.9%
- 특이사항: 모델 1보다 정확도가 향상되었으나, 추가 학습으로 인한 과적합 가능성이 있어 별도의 검증이 필요함.

### 모델 3 — 하이퍼파라미터 재조정 모델

- 학습 조건: 하이퍼파라미터 재설정 후 처음부터 학습
- 학습 설정: 30 Epoch, Batch Size 256
- 데이터 분할 비율: 7:1:2 (훈련:검증:테스트, 교수님 추천 비율)
- 정확도: 90.9%
- 성능 저하 원인 추정: 모델 1·2보다 훈련 데이터 비중이 감소하면서 학습에 활용되는 이미지 수가 줄어들어 검출 성능이 낮아졌을 가능성이 있음. 다만, 데이터 분할 비율 외의 설정도 변경되었으므로 추가적인 비교 검증이 필요함.

## 6-1. Validation Loss를 사용하지 않은 이유
1. 직접적인 성능 지표를 사용했다. 모델 선택은 에폭별 Validation AP를 기준으로 했으며, 최종 비교는 동일한 Test 데이터의 COCO AP와 PCK로 수행했다.
2. Loss는 실제 관절 검출 정확도를 직접 나타내지 않는다. Loss는 예측 분포와 정답 분포의 차이를 측정하므로, 관절 위치 검출 성능을 평가하는 AP와 PCK를 직접 비교 지표로 사용했다.
3. 과적합 여부는 Validation AP 추이로 확인했다. v2b의 AP는 1에폭 0.9237에서 12에폭 0.9286으로 상승했으며, 학습 후반에도 성능이 유지되었다. 다만 AP 추이만으로 과적합이 없다고 단정할 수는 없다.
4. 기존 Train Loss와 Validation Loss는 계산 조건이 다르다. Train에는 데이터 증강이 적용되지만 Validation에는 적용되지 않으므로, 두 값의 단순 비교는 적절하지 않다.
5. 두 모델의 Validation 데이터 구성이 다르다. 따라서 모델 간 공정한 비교에는 공통 Test 데이터를 사용한 AP와 PCK가 더 적합하다.



세번째 모델 성능은 시간 날 때 업데이트 예정 현재로서는 성능이 가장 안 좋은 모델을 조정할 이유도 없거니와 추가 동작 학습이 더 급하다고 판단.(아니 한달이 말이 됩니까 한달이)
